# PhyloParallelograms 1.1.4

## New features

- **Show QR Code** (View menu and Export button) displays the network as a QR code in the lower left corner of the
  drawing. The code holds the network in Newick format, including its annotations (the tree traces and other
  data attached to nodes and edges) if that fits into a QR code, and without them otherwise. If the network is
  too large either way, a message says so. The code can be dragged, and its context menu copies it, changes its
  size or closes it

## Touch screens (iOS app)

- A tap on a taxon label adds it to the selection, or removes it, instead of replacing the selection, as there is
  no shift key; a tap on the background clears the selection
- **Box selection**: a long press on the background followed by a drag opens the selection rectangle, as in the
  other apps; a plain drag pans the drawing. The taxa inside the rectangle are added to the selection
- The fields for the minimum branch confidence and concordance are wide enough for their numbers
- **Copy Image** no longer has an empty area on the right and at the bottom
- **Share Network as Newick** is replaced by Show QR Code; Copy Network copies the network in Newick format
