# PhyloParallelograms 1.1.2

## New features

- All data for the submitted manuscript on this approach is provided in the `publication-data` directory.
- Image export now crops the exported image to the drawing's content, removing the large white margins (most noticeable
  in PDF) while keeping the legend.
- Image export to TeX (TikZ) is now available, in addition to PNG, SVG and PDF.
- The folder last used for saving is now remembered, so the Save dialog reopens there.
- The **Show Trees Legend** setting is now remembered between sessions.
- The top toolbar is now a single row; when the window is too narrow to show every button, the extra buttons collapse
  into an overflow (») menu.
- The toolbar **Export** menu has been reorganized and now also offers **Export Image...** and **Print...**
- **File > Export > Newick...** has been renamed to **File > Export > Data...**
- The user manual has been updated.

## Bug fixes

- Image export to PDF and SVG now includes the highlighting of selected trees.
- The **Find** toolbar button now works: it is a toggle that stays in sync with **Edit > Find**.
- The **Find** toolbar now appears below the main toolbar rather than at the top of the window.
