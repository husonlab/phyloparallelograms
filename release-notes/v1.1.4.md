# PhyloParallelograms 1.1.4

## New features

- **Show QR Code** (View menu and Export button) displays the network as a QR code in the lower left corner of the
  drawing. The code holds the network in Newick format, including its annotations (the tree traces and other
  data attached to nodes and edges) only if that fits into a QR code; otherwise the annotations are removed from
  the Newick string. If the network is too large even then, a message says so. The code can be dragged, and its context menu copies it, changes its
  size or closes it

- The network toolbar is shorter: the note button, the Diagram and Settings menus, the color scheme and the zoom
  buttons moved into a second toolbar above the drawing, which a new button (three vertical dots, in front of
  Select) shows or hides. It is hidden to start with. The Settings menu now has a gear icon

## iPhone and iPad app

- PhyloParallelograms is also available as an app for iPhone and iPad, see
  <https://husonlab.github.io/mobile-apps/>. Changes that concern the app only are described with each
  update of the app, not here
