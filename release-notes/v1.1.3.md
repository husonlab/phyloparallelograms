# PhyloParallelograms 1.1.3

## New features

- New **Layout Settings** panel (in the settings panel, below PhyloFusion Settings) with a **Use reticulate edge
  multiplicities** option. When enabled (the default), the displacement-optimized network layout weights each reticulate
  edge by its *multiplicity* - the number of trees traced through it - so that reticulate edges used by many trees are
  drawn with less vertical displacement. This can noticeably reduce clutter in the parallelogram. Toggling the option
  re-lays out the network immediately, and the setting is saved with each dataset.

- Changing a **PhyloFusion setting** now recomputes the network immediately, instead of taking effect only the next time
  **Run Layout** is pressed.
